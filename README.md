# yuanqi-sizheng
“元启新思·智育红心”项目以AI+元宇宙技术为核心，构建全维度思政教育新范式。平台包含元宇宙场景交互、AI智能教学、游戏化学习、区块链证书与大数据学情分析五大模块，打破传统单向灌输模式。通过红色历史元宇宙社区、企业ESG基地、非遗孪生实验室等沉浸式场景，学生可化身角色、参与辩论、AR寻宝，学习成果以NFT证书上链存证。项目基于HTML5/Three.js纯前端实现，无需部署后端，适配多终端访问。目前已在大连财经学院等高校试点，累计学习人次超1.8万，发放链上证书4000余份，教学满意度达97%。该平台为思政教育数字化转型提供了低成本、易推广、可量产的解决方案，具有显著的社会效益与推广价值。
